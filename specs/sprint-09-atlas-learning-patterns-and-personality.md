# Sprint 09 — Atlas Learning Patterns & Relationship Brain v1

## Goal

Teach Atlas how the child tends to learn and introduce the first version of Atlas personality.

## Principle

> Atlas should understand not only what the child knows, but how the child learns.

Avoid claiming fixed scientific "learning styles".

Use the concept:

**Learning Patterns / Learning Preferences**

## Signals

Potential signals:

- Visual vs text performance
- Story/word-problem performance
- Short vs long session performance
- Response-time patterns
- Best study time
- Explanation preferences
- Motivation signals
- Engagement patterns
- Perceived difficulty patterns

Only infer patterns after enough evidence.

Use confidence levels.

## Relationship Brain

Atlas may store non-sensitive preferences such as:

- Favorite animal
- Favorite theme
- Favorite color
- Motivation style

Do not make personality the main intelligence system.

## Personality

Atlas should feel like:

- Friendly
- Encouraging
- Personal
- Concise
- Honest

Atlas is a learning coach, not a general chatbot.

## Data-Driven Encouragement

Bad:

> You're amazing!

Better:

> You solved today's questions 40% faster than yesterday.

Praise should be supported by actual data whenever possible.

## Parent vs Child Experience

Child:

- Friendly Atlas messages
- Progress feedback
- Encouragement

Parent:

- Clear progress
- Explainable recommendations
- No unnecessary technical detail

## Tests

Test:

- Learning pattern aggregation
- Confidence thresholds
- Preference persistence
- Personality response data
- Child authorization
- Parent access rules

## Out of Scope

- Open-ended AI companion
- Voice assistant
- Emotional diagnosis
- Sensitive personality profiling
- Advanced ML
