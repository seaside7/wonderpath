# Sprint 03 - Learning Session

## Goal

Allow parents to start a personalized learning session for each child.

---

## User Story

As a parent,

I want to choose what my child studies today,

So WonderPath can deliver the correct learning content.

---

## Acceptance Criteria

### Parent can

- Select one of their children
- Select one curriculum
- Select one subject
- Start a learning session

---

## Subjects (MVP)

- Mathematics
- English

---

## Curriculum

- IB
- Cambridge
- Merdeka
- Nasional

The selected curriculum must belong to the child's supported curricula.

---

## Learning Session

Create a learning session containing:

- Child
- Curriculum
- Subject
- Started At
- Status

Status:

- Started
- Completed
- Cancelled

---

## Validation

- Parent only starts sessions for their own child.
- Selected curriculum must exist in the child's supported curricula.
- Subject is required.

---
